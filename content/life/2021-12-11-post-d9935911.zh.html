兩年職涯紀錄：找工作，換工作！

畢業到現在，也出社會工作了兩年，做過兩份工作，不知道是不是我比較幸運，我遇到的人都挺好的

第一份工作在晶心科技 (Andes Technology) 擔任 Debugger Engineer，負責開發 Debugger，諸如 OpenOCD/GDB 等

我好像是第一個從外面收進來的人，Debugger 原本都是公司內轉進來的，因為是很冷門的項目，沒什麼人願意做，我也只是看到做 Open Source，感覺很高大上，就來應徵了

我們 Team 的規模很小，含我就五個人

  1. David: 軟體處的處長，負責管理我們。跟我比較沒有交集，但我覺得他就是個好好先生。
  2. HelloSun: 我的 Mentor，主要負責做 OpenOCD 開發。技術能力挺好的，我當初就是看了他寫的系統架構秘辛：了解RISC-V 架構底層除錯器的秘密！，才來應徵的。
  3. Penny: 負責 GDB 相關的維護開發，是個有豐富工作經驗的資深同事，常聽他說錯過了兩次發財機會，一次是群聯，一次是聯詠，因為當時都在很適合的時間點有機會發大財，但年輕時都沒有把握住XD
  4. Ya-Ting: OpenOCD 的二把手

對於第一份工作來說，這真的是很棒的地方，工作性質很遠離客戶端，也就不太會有時辰壓力，有很多時間可以摸索自己想要的職涯，到底是什麼？不然看 PTT 上沒有半間好的公司，不管是大間小間，錢多錢少，常常都被嫌得一文不是，對未來是很茫然的，是要進一線豬屎屋好，還是外商好，又或者是該跟著新創去作夢？

如果一開始就做步調快速的工作，也沒有時間讓思緒沉澱，搞清楚每個選擇的意義，只能被生活推得一直往前！

第二份工作(現職)在聯發科技 (Mediatek) 擔任 WiFi Customer R&D，負責 Technical Support/Windows Driver Development/FW Customize Feature Development

兩份工作幾乎是完全無關的，前者在 CPU IP 公司開發 Toolchain，後者在Design House做產品，從極度遠離客戶端，到最接近客戶端的一級戰線，這落差挺大的，一開始也有些適應不過來

現在 Team 的成員挺多的，就不一一介紹大家了，只會介紹我的 Mentor「Ivan」，他從Wi-Fi Spec 開始帶我讀，又一題一題的指導如何解題，坦白講，一年內的新人，老人不幫忙解題的話，直接面對幾百萬行的 Log，任誰都沒有辦法的，我哪知道重點在哪……

這工作包山包海的，什麼都要會，即便有一個好的領路人，要訓練一個沒有Wi-Fi 經驗的人，直到可以獨立作業，至少也需要一年以上的時間，通訊的問題真的太複雜了

任何問題進來，我們都要做第一線的分析，想辦法定位問題，但他可能是平台問題 / Driver 問題 / FW 問題 / Windows 問題 / etc.，講到這邊，那這份工作是「好」還是「不好」？有人帶，薪資福利還可以，職涯發展肯定不錯，但忙的時候工時挺長，且工作內容五花八門，十八般武藝都要會

概括來說，如果你是一個喜歡挑戰的人，這邊的挑戰挺多的，工作內容精實，步調快速，資源充足；如果你是喜歡安逸的人，快點離開吧，這對你來說絕對是地獄

那我是怎麼想？我覺得都到一線公司了，沒有什麼一線公司是不好的，差別只在選擇不一樣，不一樣的生活模式，比起很多行業，科技業至少賺錢，沒什麼好抱怨的，共勉之

那這兩個工作，聽起來都不錯，為何我會換工作？

以第一份工作來說，我想體驗不同的產業，在學生時期我寫過網頁，做過遊戲，甚至是一點點的 VR，也研究過那麼一點機器學習，現在連 Open Source 都有摸過了。那我希望藉由 Mediatek 補齊我對硬體的認識，這樣就從上層 Application (Web) 到底層的 Chip (Driver/FW)，甚至是 Toolchain 全部摸過一輪

那現職呢？又或者說我到底想要什麼？很抱歉，我還沒想好，我不知道我是想要賺更多的錢？還是追求什麼領域更深入的技術探索，還是回歸生活，工作得過且過？

那為何常常面試？只是常常收到邀請，自己投遞的面試真的不多，如果不知道幹嘛，我是覺得可以加減面面！

面試：了解自己在市場上有多少價值，最快的方式，很像是在看投資損益表，只是對象是自己XD

最後，希望大家不要單純為了薪水而換工作，再高的薪水，都沒辦法保證遇到適合的同事主管，除非你真的真的很需要錢錢~
