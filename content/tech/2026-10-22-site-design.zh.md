這個網站是純靜態的：建置時把所有頁面渲染成 HTML，部署到 GitHub Pages，讀者的瀏覽器不需要執行任何程式也能讀完內容。這篇整理設計時的幾個需求，以及各自的取捨。

## 目標

1. **每篇文章的版面可以不同。** 技術文章要一個時間軸，旅行文章要照片牆，有時想放一個可以互動的圖。不想被一種固定模板限制。
2. **圖片不進 git 歷史。** 圖片一旦被 commit，之後刪文或換圖，blob 還留在歷史裡。
3. **風險小。** 不依賴第三方服務、沒有追蹤、npm 依賴與建置流程要保守。
4. **寫作不卡。** 有原稿、有預覽、有檢查，推上去就是發佈。

## 建置與部署

- 以 Vite 與 React 為基礎，建置時用 `renderToString` 把每個路由輸出成靜態 HTML（SSG）。唯一會在瀏覽器裡 hydrate 的只有少數小元件（深淺色切換、複製連結、搜尋與季節主題的開關）。
- 路由涵蓋中英文兩種語言、技術與生活兩個分類、標籤頁與搜尋頁；兩個語言版本互相連結，沒有翻譯的文章會明講，不做機器翻譯。
- 推到 `master` 就觸發 GitHub Actions：跑同一組檢查（型別、測試、建置、站內連結、依賴弱點），再部署。Actions 都釘在 commit 雜湊，而不是浮動的版本標籤。
- 文章是否發佈由兩件事決定：不是草稿，且檔名裡的日期（以台北時間計）已經到了。

## 三種文章

| 種類 | 內容 | 適用 |
|---|---|---|
| `.md` | Markdown，**原始 HTML 一律跳脫，不會被渲染** | 一般文字 |
| `.html` | 自己排版的 HTML，經過白名單清理器 | 匯入的文章、照片牆、時間軸 |
| `trusted: true` | 內容照原樣使用，可以有自己的 CSS、JS，Markdown 裡可以放互動元件 | 需要完全客製的單篇 |

`.html` 的白名單清理器用 parse5（HTML5 標準的解析演算法）解析，再只輸出白名單內的標籤與屬性：沒有 script、frame、表單、事件處理器，也沒有 `style` 屬性；連結只允許 http(s)、mailto、站內與 `#`；**圖片必須是站內路徑**，否則建置直接報錯，不會悄悄丟掉圖片。標籤可以帶 class 與 id，外觀交給共用樣式表或該篇自己的 CSS 檔。

`trusted` 是明確的信任，匯入工具永遠不會自己寫上它。檢查流程會列出每一篇 trusted 文章、有沒有腳本，以及它的 HTML、CSS、JS 裡提到了哪些**外部主機**，第三方腳本或追蹤碼就不容易夾帶進來。

## 圖片：不進 git，也不丟

- **原圖**留在自己的硬碟或雲端，不放在任何 GitHub repo，連私有的也不放。
- **網頁版**由一個沙盒化的腳本產生：長邊 1600 px、WebP、移除 EXIF 與 GPS。它在 Docker 裡跑，沒有網路、唯讀根目錄，處理的是來源不明的圖片檔，所以不信任它。
- 網頁版放在 `content/<分類>/media/`，這個資料夾被 git 忽略。已發佈的圖片打包成 GitHub Release 裡的壓縮檔（一篇一個），部署前先下載。所以換圖或刪圖不會在 git 歷史留下任何 blob，Release 裡的檔案可以真的移除。
- 部署時下載的壓縮檔被當成不受信任的輸入：解壓腳本只接受特定路徑格式、特定副檔名的一般檔案，其他一律拒絕。
- 檢查流程會在圖片被 git 追蹤時失敗。
- 預覽時可以在「網頁版」與「原圖」之間一鍵切換，只在本機開發時有效，線上永遠是網頁版。

## 搜尋與標籤

搜尋完全在瀏覽器裡做，沒有伺服器、沒有第三方：

- 建置時為每個語言寫出一份很小的索引（約每篇 0.25 KB），只含**已發佈**的文章；頁面在輸入框取得焦點時才下載。
- 比對方式是子字串，所以中文不需要斷詞；每個詞都要命中，標題的分數比小標題高，小標題比摘要高。內文不進索引，真的需要時再換成 Pagefind 這類分塊索引，而不是讓這個檔案變大。
- 標籤整合在搜尋頁：預設列出幾個常用標籤，輸入 `#標籤` 再按空白鍵，那個詞會變成輸入框裡的標籤晶片，晶片與一般關鍵字可以組合。輸入法組字中不會改動文字，否則中文會被打斷。
- 檢查流程會確認私有文章的標題沒有出現在任何索引裡。

## 供應鏈與隱私

- 所有指令都在 Docker 裡執行：唯讀根目錄、不給額外權限、不安裝東西到主機。
- 依賴一律精確釘版本，`ignore-scripts` 開啟（套件不能在安裝時執行程式），只採用發佈滿一段時間的版本，並驗證過 npm 套件的簽章。已知但可接受的弱點用允許清單記錄，而且**每一筆都有到期日**，到期後檢查會再次失敗。
- 沒有追蹤、沒有外部字型、沒有第三方腳本；站內圖片都是自己的。

## 季節主題

萬聖節那幾週，網站會自動換上暖橙與紫黑的配色，有蝙蝠和南瓜在畫面上飄。判斷日期**在瀏覽器裡**做，因為網站只在發佈時建置一次，如果在建置時判斷，過了日期就會過期。一小段內嵌腳本在第一次繪製前設定屬性，所以不會閃一下；網址加上 `?season=halloween` 或 `?season=off` 可以強制預覽。動畫尊重「減少動態效果」的設定，沒有 JavaScript 時就是一般的主題。

## 限制

- GitHub Pages 不能設定 HTTP 標頭，所以沒有 Content-Security-Policy，只能靠不載入第三方內容來降低風險。
- 沒有排程建置：未來日期的文章要等到那天之後的第一次推送才會上線，或手動觸發部署。
- 內文不在搜尋索引裡。
